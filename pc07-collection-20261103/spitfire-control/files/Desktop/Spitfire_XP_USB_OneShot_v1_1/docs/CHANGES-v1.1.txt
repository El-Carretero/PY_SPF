Spitfire XP USB 1회 자동시험 — v1.1 변경 내역

수정 배경
현장 로그의 세 번째 회차는 View 메뉴를 연 뒤 메뉴 크기 검사에서 중단됐습니다.
현장 팝업은 170×74픽셀, 기존 VM 팝업은 195×70픽셀이었습니다.
항목을 누르기 전의 차단이었으며, PCAP 기록 자체는 정상적으로 남아 있었습니다.
앞선 두 회차는 이미 열린 설정/서비스 창 때문에 의도적으로 차단된 경우입니다.

수정 내용
- View/Help 메뉴 제목 및 항목 위치의 고정 좌표 의존성을 제거했습니다.
  검증된 CVI 런타임에서 메뉴 ID, 항목 ID, 콜백, 라벨, 활성 상태와 실제 경계를
  읽고, 허용된 항목에 한해 클릭 직전에 다시 확인합니다.
- 메뉴/글꼴 정보를 확인할 수 없거나 클릭 전 상태가 바뀌면 입력하지 않습니다.
  heading-layout 및 menu-layout 진단 파일을 남깁니다.
- 창을 닫은 뒤 CVI가 메뉴바에 기록하는 정확한 내부 폭 값 4096도 처리합니다.
  실제 메뉴 제목의 클릭 영역은 화면에 보이는 895픽셀 창 안으로 제한합니다.
- 정상적으로 남은 native 오류 86을 일반적인 증거 누락 오류로 덮어쓰지 않습니다.
  실제 종료 코드, 세부 사유, 열린 창 이름, 해당 증거 링크를 보고서에 표시합니다.
- XP에서 캡처 상태 파일을 교체하는 순간 발생한 읽기 잠금 충돌을 처리합니다.
  공유 읽기를 지원하는 native 도우미가 별도 사본을 만든 뒤 실행기가 읽습니다.
  원래 캡처 시각을 보존하며, 읽기 실패나 오래된 상태를 성공으로 취급하지 않습니다.
- 이미 열린 보조 창, 숫자 편집 포커스, Opt-out OFF, 통신 이상 차단은 유지합니다.
  보조 창을 자동으로 강제 닫거나 Opt-out/표시 모드를 변경하지 않습니다.

유지되는 범위
패킷 캡처 도구, WinPcap 설치 도구와 공식 설치 파일은 v1과 동일합니다.
캡처 상태 파일 전달 도우미와 실행기는 위 읽기 충돌 처리를 위해 수정됐습니다.
원본 프로그램 시작/종료/재시작, 설정 변경, Laser/HV/온도 조작은 추가하지 않았습니다.
사용자는 원본이 이미 실행되고 통신 중이며 메인 화면만 열린 상태에서 실행합니다.

검증 범위와 회차별 결과는 VALIDATION.txt 및 validation-summary.json을 봅니다.
현장 원본 로그는 수정하지 않았으며, 이번 재시험 대상은 격리된 p07 XP VM입니다.
