시험 범위
20255566-p07의 격리된 VMware XP에서 원본 Spitfire 사본과 시뮬레이터로 시험했습니다.
연결 상대의 응답은 시뮬레이터가 생성한 값입니다. 실물 제어 PC/컨트롤러에는 v1.1을 재실행하지 않았습니다.
VM 준비 과정에서는 시험용 사본을 별도 실행했습니다. 사본 시작 시의 EMP:LBOBREAK 명령은
격리 시뮬레이터가 거부했으며, 아래 자동시험 캡처 구간과 구분해 검증 자료에 기록합니다.
USB 배포 프로그램 자체는 원본을 시작하거나 종료하지 않습니다.
제공받은 현장 로그는 읽기 전용으로 분석했습니다. 시험 조건 메타데이터가 없으면
특정 글꼴/DPI 또는 현장 화면 환경을 재현했다고 주장하지 않습니다. 조건 원문은 요약 JSON에 남깁니다.

v1.1에서 확인하는 동작
현재 표시 모드를 유지한 Temperature, Timing, Faults, Setup, About 5단계를 처리했습니다.
각 회차의 실제 표시/생략 여부는 result.json에 기록되며 비활성 Setup은 클릭하지 않습니다.
선택된 성공 회차는 모두 사용자 표시 모드(0)입니다. 이미 서비스 모드(1)인 경우의
분기는 이번 최종 VM 회차에서 실행하지 않았으며, 모드 전환 입력도 하지 않았습니다.
메뉴 신원과 실제 항목 경계를 검사한 뒤 허용된 조회 항목만 선택합니다.
기존 보조 창이 열려 있거나 편집/포커스 상태를 확인할 수 없으면 입력을 차단하는 보호 조건은 유지합니다.
native 오류 코드와 세부 사유 및 열린 창 이름을 보고서에 보존합니다.
원본 시작/종료/재시작, 키 입력에 의한 표시 모드 전환, Laser/HV/온도/파라미터,
Opt-out 변경, reset/interlock 우회는 실행 경로에 포함하지 않습니다.

캡처 및 무결성 확인
선택된 모든 회차: 변경 명령0, 드롭0, 캡처 오류0, 양방향 패킷 기록 확인.
완료된 classic PCAP의 SHA256/크기와 독립 감사 결과를 다시 대조했습니다.
독립 Python 감사는 PCAP 프레임과 packets.jsonl의 시각/길이/UDP 페이로드/태그 집계를 검사합니다.
모든 회차는 독립 tcpdump/libpcap으로도 끝까지 읽었습니다.
기록 경계에서 송신/응답 수는 다를 수 있습니다. XP의 시계를 사용하며 외부 시각과 동기화했다고 주장하지 않습니다.
실제 회차에 복사된 실행 파일 9개의 크기/SHA256을 현재 배포 대상 파일과 모두 비교했습니다.
회차별 조회와 주기는 OBSERVED-QUERIES.csv를 봅니다. 원본 근거는 USB 배포 ZIP의
validation/evidence/sessions 및 별도 검증 ZIP의 evidence/sessions에 있습니다.

드라이버 설치 검증 구분
포함된 WinPcap 4.1.3 공식 설치 파일과 설치 도우미는 이전 v1에서 확인한 구성요소와 동일합니다.
신규 설치 자동화의 실제 XP 성공 근거는 이전 v1 시험이며, 이를 v1.1 신규 설치 재시험으로 표시하지 않습니다.
버전·출처·서명·SHA256 및 이전 설치 범위는 capture-dependency-provenance.json을 봅니다.

아직 확인하지 않은 범위
수정본의 실물 제어 PC 실행, 실제 컨트롤러의 응답 의미/값/시간/펌웨어 차이 및 물리 보호 동작은 미확인입니다.
시뮬레이터 응답이나 화면 표시로 실제 Laser/HV/온도/인터록 동작을 검증했다고 해석하지 않습니다.
회귀 검사 결과는 tests/*-test-results.txt 및 revision-review-*-results.txt를 봅니다.
