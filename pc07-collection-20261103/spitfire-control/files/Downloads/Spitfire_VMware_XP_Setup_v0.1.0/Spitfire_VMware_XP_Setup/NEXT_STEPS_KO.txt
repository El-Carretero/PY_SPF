XP 설치 후 Spitfire 검증 환경 연결

원본 Spitfire는 XP 가상머신 안에 설치합니다.
Spitfire Twin Verifier v0.2.0은 Windows 10/11 호스트에서 Python 3.10 이상으로 실행합니다.
이 패키지에는 Spitfire, 검증 코드, Python, VMware Tools가 포함되어 있지 않습니다.

1. 초기 XP 상태의 스냅샷을 저장합니다.
2. VMware 가상 네트워크 편집기에서 VMnet1이 Host-only로 설정되었는지 확인합니다.
   호스트 가상 어댑터가 활성화되어 있어야 합니다.
   XP의 지원이 종료되었으므로 검증망은 인터넷과 분리해 사용하는 구성입니다.
3. 이전 검증 구성에 맞추려면 VMnet1의 서브넷을 10.19.70.0 / 255.255.255.0으로
   설정하고, 충돌하지 않도록 DHCP 주소 범위를 확인합니다.
   이 변경은 VMnet1을 공유하는 다른 VM에도 영향을 줍니다.
   기존 환경에서 이 대역을 사용 중이면 검증 코드의 주소와 함께 조정해야 합니다.
4. IP 구성 예:
   호스트 VMnet1 어댑터 기본 주소: 10.19.70.1 / 255.255.255.0
   호스트 VMnet1 어댑터 추가 주소: 10.19.70.13 / 255.255.255.0
   XP 가상머신의 고정 주소:       10.19.70.2 / 255.255.255.0
   이 검증 전용 어댑터에는 기본 게이트웨이와 DNS를 지정하지 않습니다.
   .1과 .13은 같은 호스트 어댑터에 설정하는 서로 다른 주소입니다.
5. 원본 Spitfire를 XP에 설치하고, 호스트의 검증 코드를 구성합니다.
   기존 구성의 엔드포인트는 다음과 같습니다.
   Python Control: 10.19.70.1:1024
   원본 Spitfire:  10.19.70.2:1024
   가상 장치:     10.19.70.13:1024
   프로토콜 및 실행 명령은 검증 패키지의 README를 따르세요.

설치 도우미는 위 IP 주소, 방화벽, Spitfire 설치를 자동으로 변경하지 않습니다.
XP 내부 파일 전송은 설치 매체를 ISO로 연결하는 방법 등으로 진행할 수 있습니다.
VMware Tools가 필요하다면 XP와 호환되는 버전을 확인해야 합니다.
