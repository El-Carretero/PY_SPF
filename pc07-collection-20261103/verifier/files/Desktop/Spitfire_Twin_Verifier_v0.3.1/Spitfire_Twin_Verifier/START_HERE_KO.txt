Spitfire Twin Verifier 0.3.1 — 시작 안내
=======================================

0.3.1: Windows에서 설정 파일을 동시에 저장할 때 발생한 경합 수정.
같은 프로세스 내 읽기·쓰기를 직렬화하며, 실제 권한 오류는 숨기지 않습니다.
별도 프로세스 간 저장 잠금이나 XP 실동작 검증을 추가한 버전은 아닙니다.
이번 수정/시험 결과: docs/RELEASE_CHANGES_0.3.1.txt

1. ZIP 전체를 새 폴더에 풀어 주세요. ZIP 안에서 직접 실행하지 마세요.
2. Start-SpitfireTwinVerifier.bat 를 더블클릭합니다.
   dist의 EXE가 있으면 Python 설치 없이 화면이 열립니다.
   소스 배포판은 Python 3.10 이상(Tk 포함)이 필요합니다.
3. 첫 번째 '버전·시나리오' 탭을 사용합니다.

가장 쉬운 검증
-------------
[ZIP 추가]에서 비교할 Spitfire Python Control ZIP들을 고릅니다.
파일 검사만으로는 소스를 실행하지 않습니다.
[추가한 코드로 loopback 시험] → 신뢰하는 코드인지 확인 → 결과 표 확인.
이 기능은 별도 Python 3.10+가 필요합니다(EXE 사용 시에도).
PASS / FAIL / UNSUPPORTED를 구분합니다.
[시험 JSON / HTML 저장]으로 결과를 보관합니다.

외부 펌프·트리거 시험
--------------------
시나리오 선택 → [모델 자체 시험].
12개 내장 시나리오는 가상 정책의 자체 시험입니다.
이 PASS는 XP/Python 프로그램이나 실제 장비가 통과했다는 뜻이 아닙니다.
클라이언트 반응에는 실제 코드 loopback 시험 또는 별도 캡처가 필요합니다.

XP 프로그램과 실제 화면을 비교하려면
-----------------------------------
XP는 가상머신 내부, Verifier는 Win10/11 호스트에서 실행합니다.
실제 레이저와 분리된 Host-only 네트워크를 사용합니다.
기본 수신 주소127.0.0.1은 안전한 로컬 시험 전용입니다.
XP용10.19.70.13:1024 설정은 docs/USER_GUIDE_0.3.0_KO.txt를 읽고
격리된 가상 어댑터에만 적용하세요. 네트워크 자동 변경은 하지 않습니다.
XP 원본이 실제 실행된 것으로 표기하지 않습니다. P07에서 XP VM은 확인했지만
원본은 미설치 상태이며, 네트워크/관리자 승인 준비가 남아 있습니다.
