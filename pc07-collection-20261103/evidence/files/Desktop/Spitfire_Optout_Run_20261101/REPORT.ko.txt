Opt-out
시작 시 OFF를 확인했습니다. 01:51:44.846–01:51:47.601의 사용자 직접 조작에서
[2036]EMPOPTOUT 1 여섯 번과 EMPOPTOUT 0 다섯 번을 기록했습니다.
사용자가 해당 조작을 직접 했다고 확인한 내용을 별도 증거로 보존했습니다.
시뮬레이터는 ON만 RAM에 적용했고 OFF는 거부했습니다. 이후 원본 내부 상태는 ON이었습니다.
[1068]EMPOPTOUT? 응답은 초기 0, 재시작 1, 재접속 1이었습니다.
초기 자동 클릭 시도는 변경에 실패했고, 후속 자동화는 이미 ON이어서 입력하지 않았습니다.
수정한 자동 ON 클릭의 성공으로 이 수동 전환을 해석하지 않습니다.
