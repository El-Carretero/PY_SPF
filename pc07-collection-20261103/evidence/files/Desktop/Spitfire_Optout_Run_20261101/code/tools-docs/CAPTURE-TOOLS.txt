Spitfire XP 통신 수집 — 캡처 도구와 공식 설치 자료
작성 기준: 2026-11-01 (Asia/Seoul)

이번 실행에 선택한 도구
  p07 호스트의 Windows 내장 Packet Monitor(Pktmon)를 사용한다.
  pktmon.exe / PktMon.sys 버전: 10.0.26100.9949 (WinBuild.160101.0800)
  대상: VMware Network Adapter VMnet1, 현재 확인한 component ID 12.
  전체 패킷 수집: --pkt-size 0. 기본값 128바이트를 사용하지 않는다.
  게스트·원본 PC에 Wireshark/WinPcap/Npcap 설치가 필요하지 않다.
  재실행 때 VMnet1, component ID, 격리 설정, 기존 캡처 세션을 다시 확인한다.

캡처·변환 방법
  격리·Opt-out·시뮬레이터 확인 및 기존 Pktmon 세션 부재 확인 후,
  호스트 관리자 터미널에서 현재 VMnet1 component를 사용한다. 예:
    pktmon start --capture --comp 12 --pkt-size 0 --log-mode multi-file --file-name RUN.etl
    [허용 목록의 게스트 동작 실행]
    pktmon stop
    pktmon etl2pcap RUN.etl --out RUN.pcapng
  필터는 해당 실행의 상위 실행 스크립트에 따라 설정한다.
  원본 ETL과 pcapng를 보존한다. 생성된 모든 ETL 분할 파일을 확인한다.
  classic pcap 변환·검증은 상위 폴더 pcap_audit.py를 사용한다.
    python pcap_audit.py RUN.pcapng RUN.pcap --provenance original
  original 플래그는 실제 원본 실행 파일의 프로세스·타임라인 근거가 있을 때만 쓴다.
  진단 코드의 패킷에는 --provenance diagnostic을 사용한다.
  변환기는 프레임 바이트를 유지하고 송수신 존재·잘림·블록 구조를 검증한다.
  실제 캡처의 성공·완전성 판정은 해당 실행 결과 보고서를 참조한다.
  이 문서는 이번 원본 프로그램 캡처가 검증 완료되었다는 보고서가 아니다.

다운로드·검증 자동화
  동봉 Fetch-CaptureTools.ps1은 p07 같은 현대 Windows 호스트에서 실행한다.
    powershell.exe -NoProfile -File .\Fetch-CaptureTools.ps1 -Destination .\official-downloads
  공식 HTTPS URL에서 받으며, 공개 SHA1 일치 확인 후 SHA256, 크기,
  Authenticode 상태·서명자·시각을 integrity.json에 기록한다.
  기존 다운로드도 다시 해시 검증하며 SHA1 불일치 시 실패한다. 설치는 하지 않는다.
  검증된 파일만 기존 격리된 파일 전달 경로로 XP에 전달한다.
  XP의 인터넷 연결을 추가하거나 원본 실물 PC에 도구를 설치하지 않는다.
  과거 실제 다운로드 결과: evidence/prior-official-download-integrity.json
    양쪽 공식 SHA1 일치, Authenticode Valid, installed=false.
    Wireshark 서명자: Wireshark Foundation
    WinPcap 서명자: Riverbed Technology, Inc.
  SIGNATURES-1.10.14.txt를 보존했지만 PGP 서명 검증을 수행했다고 주장하지 않는다.
  SHA256은 다운로드 파일 식별값이며 별도 게시자의 SHA256 검증 결과가 아니다.

XP 설치가 별도로 필요해질 때의 명령과 제한
  검증 후 XP에서 Wireshark의 공식 무인 설치 명령 예:
    start /wait "" Wireshark-win32-1.10.14.exe /S /desktopicon=no /quicklaunchicon=no
  /S는 WinPcap을 설치하지 않는다. /NCRC는 사용하지 않는다.
  WinPcap_4_1_3.exe는 공식 GUI 설치를 사용한다. /S 지원을 가정하지 않는다.
  WinPcap의 무인 GUI 설치는 이번 실행에서 구현·시험하지 않았다.
  필요한 경우 게스트 내부 코드로 실제 설치 창·버튼을 먼저 식별한 뒤 자동화한다.
  설치 후 dumpcap -v, dumpcap -D, sc query npf 및 실제 양방향 수집을 확인한다.
  dumpcap 1.10.14는 -P로 구형 Wireshark 호환 classic pcap을 기록할 수 있다.
