# 1.3.2 ARM/reset 시험 근거

최종 성공한 실기 응답 기반 GUI 시험은 `live_gui_automated_run02/summary.json`입니다.
`live_gui`는 화면 제어가 창을 선택하지 못해 ARM 조작을 완료하지 않은 실행입니다.
`live_gui_automated`는 ARM 유지까지 성공했으나 HV readback이 오래되어 reset 확인 단계에
진입하지 못한 최초 자동 시험입니다. 해당 실패 기록도 보존했습니다.
두 번째 자동 시험은 HV를 명시적으로 새로 조회한 뒤 reset 경로를 확인했습니다.

모든 live 실행의 실제 송신은 조회만 허용했습니다. reset 요청은 최종 송신 검사 통과 후
시험용 transport에서 취소했으며 장치로 보내지 않았습니다. 정상 ACK를 만들어 넣지 않았습니다.
실제 장치의 fault가 해제됐다는 검증은 아닙니다.

이 폴더의 스크립트는 이 PC의 경로와 장치 주소에 고정된 시험 기록입니다.
범용 실행 도구가 아니므로 다른 환경에서 그대로 실행하지 마십시오.
