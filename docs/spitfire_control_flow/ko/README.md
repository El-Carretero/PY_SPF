# Spitfire 하드웨어–소프트웨어 통합 제어 흐름

**XL-TR-SPF-001 · REVIEW · Draft 0.2 · 2026년 11월 2일 · INTERNAL**

## 핵심 결과

**RUN 요청, 소프트웨어의 허용, 명령 전송, 제어기의 상태 회신, 실측된 광학 방출은 서로 다른 사건이다.** 확보된 근거로 통합적인 기능 관계와 특정 소프트웨어·로그 관측을 설명할 수 있다. 그러나 전체 펌웨어 회로, 설치된 인터록의 유효성, 실제 광학 방출까지 입증되지는 않는다.

분석 대상은 **2005년형 Spectra-Physics Spitfire, SPTF-100F-1KHPR**이다. 제공된 제조사 문서는 **Spitfire Pro F/40F/PM**을 설명한다. 이 문서에 기술된 동작 원리는 **MANUAL**로 인용한다. 다만 명판, 출하 보고서, 배선 기록, 펌웨어 사양이 대조되기 전까지 개별 설치 부품에 대한 적용 여부는 **UNKNOWN**으로 남긴다. 본 보고서는 역설계 분석이며, 운전 절차나 레이저 가동 허가를 의미하지 않는다.

### 해석 범위

본 보고서는 제공된 xLaPPLAs 발행 양식에 따라 내용이 대응하는 영문판과 한글판으로 작성했다. 두 판의 출처와 기술적 주장 범위는 동일하다. 핵심 결과는 소프트웨어의 준비 상태와 GUI의 `EMISSION` 표시만으로 증폭된 광학 출력을 입증할 수 없다는 점이다. 보존된 기록에서는 일치하는 리셋 ACK가 수신되어도 BWD가 래치 상태를 유지했다. 제조사가 설명하는 정상 복구에는 안정적인 모드 잠금 Seed 광과 두 BWD 광검출기 표시의 녹색 상태가 필요하다.

## 주요 분석 결과

- **CODE VERIFIED / XP/LOG VERIFIED:** Native 1.0은 원본의 전역 `ON`/`OFF` 명령 계열을 유지하지만, 태그 일치 처리, 횟수가 제한된 조회 재시도, UI 스레드 스케줄링 및 복구 동작을 추가했다. 이 차이만으로 펌웨어의 전체 구동 순서가 밝혀지는 것은 아니다.
- **CODE VERIFIED:** Native 1.0은 초기화 중 보드에 Empower opt-out을 쓰는 것을 기본값으로 한다. 이 설정은 보드 구성과 일부 GUI 해석에 영향을 주지만, 설치된 외부 펌프의 배선을 입증하지는 않는다.
- **MANUAL:** BWD는 대역폭 검출기다. 정상 리셋 복구 전에는 스펙트럼의 적색·청색 측 광검출기 신호가 모두 임계값을 충족해야 한다. 전자적인 Internal 타이밍 소스만으로 이 광학 조건이 충족되지는 않는다.
- **XP/LOG VERIFIED:** 보존된 실장비 로그에는 BWD 응답 10,464줄이 있으며, 두 래치 비트 중 어느 하나라도 해제된 응답은 0줄이었다. 태그가 일치하는 리셋 수신 확인은 44회였다. 이 자료는 공백 구간이 있는 표본 기록이며, 모든 시점의 연속 관측을 의미하지 않는다.
- **CODE VERIFIED:** 원본 방식의 `EMISSION` 표시는 Empower 상태 비트를 따르며, Empower opt-out 상태에서는 갱신을 건너뛴다. Spitfire 출력 빔의 독립적인 측정값이 아니다.
- **UNKNOWN:** 설치된 모델과 매뉴얼의 정확한 대응, 펌웨어 내부의 전역 명령 효과, 전체 인터록 배선 및 실제 광학 출력은 아직 검증되지 않았다.

## 안전 및 권한 범위

**경고 — 가동 중 레이저 및 고전압 위험.** 도면이나 소프트웨어 상태 회신만으로 빔 차폐, 인원 보호, 저장 에너지의 방전 또는 인터록의 유효성을 확인할 수 없다. 소프트웨어 표시를 잘못 신뢰하면 노출, 감전 또는 장비 손상이 발생할 수 있다. 본 보고서는 분석용이다. 기재된 명령 예시를 실행하거나 인터록을 연결해 우회하는 데 사용해서는 안 되며, 장비 모델에 맞는 제조사 절차와 승인된 현장 SOP를 대체하지 않는다.

제조사는 Seed 입력을 차단해도 펌핑된 시스템이 발진할 수 있는 특수 정렬 운전을 설명한다. 따라서 Seed 부재나 숨겨진 GUI `EMISSION` 표시를 위험한 출력이 없다는 근거로 사용해서는 안 된다(MAN-330A, 인쇄 A-2 / PDF 96; 모델 적용 범위 제한 참조). 마지막 장의 권고는 감독하에 수행할 검증 제안이며, 완료된 시험이나 안전 운전값을 뜻하지 않는다.

## 작성 설정과 제작 기록

기계 판독 가능한 작성 설정은 [tools/publication.json](../tools/publication.json)과 [tools/publication-ko.json](../tools/publication-ko.json)에 있다. 제공된 표준은 A4 페이지 구성, 타이포그래피, 회색조, 머리말 식별 정보, 캡션, 표, 검색 가능한 내장 글꼴 및 검토 기록의 기준이다. 한글판은 동일한 페이지 여백, 정보 위계 및 명목 글자 크기를 유지하면서 한글에 내장 한국어 글꼴을 사용한다. 공식 작성 템플릿과 기계 판독 가능한 디자인 계약 파일은 제공되지 않았다. 따라서 편집 가능한 클래스는 공식 템플릿을 표방하지 않고, 규범 PDF를 바탕으로 구현한 파생 양식임을 명시한다. 최종 빌드와 페이지 검토 기록에는 실제 완료한 검사만 기록했다.

출처 기록은 [evidence/source_manifest.json](../evidence/source_manifest.json)에 있다. 원본 첨부 자료는 프로젝트 소유자가 보관한다. 명시된 명령과 상태 비트는 각 분석 기준 내의 근거다. 복원된 구현 동작을 제조사 하드웨어 사양으로 확정하지 않는다.
