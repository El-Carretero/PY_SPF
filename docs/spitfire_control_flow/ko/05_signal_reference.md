# 5. 신호 및 상태 참조

이 참조는 물리 입력, 컨트롤러 텔레메트리, 소프트웨어 선택을 구분한다. **MANUAL** 항목은 MAN-330A의 Spitfire Pro 구성을 설명한다. 명판, 출하 보고서, TDG 리비전, 설치 배선을 대조하기 전까지 사용자 장비 **2005 SPTF-100F-1KHPR**에 대한 적용 여부는 **UNKNOWN**이다. **CODE VERIFIED**는 커밋 `cebcc28490f48e9e5d4d1c2e2feef34d638244e7`에 고정된 Python 구현에서 해당 대응 관계를 확인했다는 뜻이다. **XP/LOG VERIFIED** 관측은 보고서에서 별도로 식별하며, 관측 결과가 가능한 모든 물리 상태를 자동으로 검증하지는 않는다.

표에서 **고장(fault)**은 출처가 명시적으로 보고하거나 설명한 고장을 뜻하고, **억제(inhibit)**는 문서에 설명된 기능이 동작 또는 증폭 출력을 막는 것을 뜻한다. 한 조건이 둘 다에 해당할 수 있다. **UNKNOWN**은 제공된 근거로 동작이 입증되지 않았다는 뜻이며, 보호 기능이 없다는 뜻이 아니다. “연속”은 동작 중 의존 관계를 뜻하며 측정된 스캔 주기나 펌웨어 처리 간격을 뜻하지 않는다. 이 참조를 작성하기 위해 장비에 명령을 보내지 않았다.

MAN-330A는 해당 시드 동기화 입력에 대해 내부 전환 가능한 50 Ω 임피던스와 250 ps 미만의 지터를 명시한다(인쇄면 4-6, PDF 52쪽). 이 값만으로 입력 전압 범위, 전체 종단 구성, 커넥터 핀 배치, 펄스 폭, 실제 설치 지터가 주어지는 것은 아니다. 대상 하드웨어의 이러한 세부 사항은 **UNKNOWN**이다. TTL이라는 표현은 매뉴얼의 펌프 트리거 설명에 해당하며, 이 보고서의 모든 커넥터나 상태 비트에 적용되지 않는다.

문서상 제어 경로는 컴퓨터 Ethernet → TDG **10BaseT**이다. TDG **PWR SUPPLY COMM** 26핀 D-sub는 Empower 전원장치의 RS-232 커넥터에 연결되고, **LASER COMM** 26핀 D-sub는 헤드 엄빌리컬에 연결된다[M-4.5; M-4.6]. 이 통신 연결들은 BNC 타이밍 입력 및 고전압 케이블과 별개이다. 핀 배치와 실제 외부 펌프 개조 구성은 **UNKNOWN**이다(설치된 펌프 배선, 6절).

BWD 리셋 콜백은 `TDG:RESBWD` 뒤에 `TDG:STBHFLT?`를 큐에 넣는다. 리셋 요청/ACK는 보호 복구를 측정한 결과가 아니다. | **CODE VERIFIED** C-SIG-4, C-SIG-5, C-SIG-6. |

| `EMP:STB?` → 펌프 상태 위젯 | 하위 바이트 비트 0 → 펌프 켜짐 위젯, 상위 바이트 비트 1 → COUNT, 상위 바이트 비트 0 → RAMPING이다. EMISSION 바는 펌프 켜짐 **또는 COUNT**에서 보인다. 소프트웨어 READY는 펌프 켜짐, COUNT, 고장, LBO 안정 상태에도 의존한다. | GUI가 해석한 펌프 텔레메트리이다. 실제 다이오드 광이나 셔터 위치를 독립적으로 확인하지 않는다. | 정규 폴링에 포함되며, 세부 펌웨어 전이 시간은 UNKNOWN이다. | **CODE VERIFIED** C-SIG-3. |

### 서로 다른 INTERNAL의 세 가지 용도

| 선택 | 소스/영역 | 근거로 확인되는 설명 | 입증되지 않은 대체 관계 |
|---|---|---|---|
| Empower QSW SOURCE INTERNAL | `EMP:QSW:SOURCE`; 펌프 전원장치 클록 | 제조업체는 공장에서 설정한 내부 Q-switch 반복률 소스로 설명한다. EXTERNAL은 펌프 후면 EXT QS TRIG IN을 사용하며 HOLD OFF는 별도의 서비스 상태이다. | TDG 시드 잠금을 입증하거나 물리적인 시드/BWD 요구를 없애지 않는다. |
| TDG 오실레이터 INT/EXT | `TDG:OSC:MODE`; 콜백과 읽기 응답 | 코드는 서로 다른 `INT`/`EXT` 값을 보내고 반환 문자열을 오실레이터 모드 위젯에 대응시킨다. 초기화 디코더는 응답에 `INT`가 없으면 INT 다음 EXT를 큐에 넣을 수 있다. | 펌웨어 클록 경로, 시드 기준 신호 합성, 설치 보정은 UNKNOWN이다. |
| TDG 트리거 INT/EXT | `TDG:TRIG:MODE`; 콜백과 읽기 응답 | 코드는 별도 모드 요청을 보내고 보이는 트리거 제어 항목을 바꾼다. | 선택된 TDG 반복률이 펌프 광자를 만들거나, 교체 펌프를 작동시키거나, 펌프/시드 인터록을 충족한다고 입증하지 않는다. |

첫 행은 **MANUAL**[M-6.11], 뒤의 두 행은 **CODE VERIFIED**[C-SIG-1; C-SIG-2; C-SIG-9]이다. 캡처된 INT/EXT 응답은 그 관측 상태에 대해 **XP/LOG VERIFIED**일 수 있지만, 코드를 넘어선 물리적 의미는 여전히 **UNKNOWN**이다. 이 구분은 한 하위 시스템의 INTERNAL 문구를 전체 레이저에 대한 통합 설명으로 재사용하는 것을 방지한다.

## 5.4 독립적인 광학 입증의 경계

유용한 근거 사슬은 **요청 → 수락된 장비 응답 → 디코딩된 상태 → 측정된 전기 타이밍 → 측정된 광학 펄스**이다. 앞의 세 단계는 소프트웨어 추적에서 확인할 수 있으나, 어느 것도 마지막 두 단계를 자동으로 입증하지 않는다. GUI EMISSION 바는 펌프 상태 텔레메트리이다. PD1/PD2는 BWD 검출기 해석이다. TDG 주파수는 반환된 측정값이며 PC 활성화/HV 읽기 응답은 컨트롤러 상태이다. 이들 어느 하나만으로 증폭 출력, 펄스 에너지, 펄스 폭, 스펙트럼 대역폭, 빔 품질, 올바른 포획/방출 위상이 입증되지는 않는다.

MAN-330A는 외부 출력 측정, 고속 포토다이오드/오실로스코프, 자기상관 측정을 권장하며(인쇄면 6-1 및 6-3, PDF 61 및 63쪽), 타이밍, 인터록, 드라이버, 광학 정렬에 관련된 무출력 사례를 명시한다(인쇄면 8-1/8-3, PDF 87/89쪽). 이 보고서에는 사용자 장비에서 독립적으로 획득한 광학 측정이 없다. 따라서 소프트웨어 상태가 **CODE VERIFIED** 또는 **XP/LOG VERIFIED**여도 광학 성능에 대한 결론은 **UNKNOWN**이다.
